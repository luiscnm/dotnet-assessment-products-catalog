# Assessment 1: MVC Products Catalog with SQLite Database Connection

### 📋 Overview
You are tasked with completing a simple product catalog web application using ASP.NET Core MVC and SQLite database. The application has a basic structure already set up, and you need to implement the required functionality.

### 🎯 Objectives (30 minutes)
Your task is to implement the following features:

1. **Products List Page** (Index)
   - Display all products from the database in a table or card layout
   - Show: Product Name, Description, Category, Price, and Stock quantity
   - Add a "View Details" link/button for each product
   - Add a "Delete Product" link/button for each product

2. **Product Details Page**
   - Create a details view that shows all information about a single product
   - Include: Product Name, Description, Category, Price, Stock quantity
   - Add a "Back to List" link/button
   
3. **Product Soft Deletion Feature** 
   - Create a Delete Product Confirmation View 
   - Include information that identifies the product to be deleted
   - Add a "Back to List" link/button
   - Add a "Delete Product" button to confirms the soft delete
   - Add the required code in the controller to process the soft deletion

### 📚 What's Already Provided
- ✅ A working ASP.NET Core MVC project structure
- ✅ SQLite database with sample data (10 products) that will be created when running the app
- ✅ Product model and DbContext configured
- ✅ Basic controller with empty actions
